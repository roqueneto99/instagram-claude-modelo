# Comece aqui

Copie a mensagem abaixo inteira, cole no Claude do seu computador (Claude Code) e vá respondendo. Não precisa clicar em mais nada nesta página.

```
Quero publicar no meu Instagram por aqui. Instale para mim o modelo https://github.com/roqueneto99/instagram-claude-modelo, do começo ao fim.

1. Antes de tudo, leia o roteiro em https://raw.githubusercontent.com/roqueneto99/instagram-claude-modelo/main/.claude/commands/instalar.md e siga à risca.
2. Crie na minha conta do GitHub uma cópia pública desse modelo, baixe a pasta para este computador e trabalhe dentro dela. Se a pasta já existir, continue de onde parou.
3. Faça você mesmo tudo o que conseguir. Se tiver o Claude no Chrome, abra e preencha as telas do GitHub e da Meta para mim.
4. Só pare quando for algo que só eu posso fazer: entrar numa conta, confirmar segurança, clicar em gerar token e colar o token. Nessas horas, me diga em uma frase o que fazer.
5. Nunca leia, peça ou grave token ou senha, e não publique nada.

A instalação só termina quando o teste mostrar "Conexão OK". Pode começar.
```

Se parar no meio, cole a mesma mensagem de novo: o Claude continua de onde parou.
