# Instagram pelo Claude

Você pede um post ao Claude, aprova a arte e a legenda, diz "publica" e ele sai no seu Instagram. Sem custo: usa a API oficial da Meta e o GitHub. Nada é publicado sem o seu "publica".

**O que precisa ter:** conta no GitHub, Instagram em modo profissional, conta no Facebook e o Claude Code no computador. Com o Claude no Chrome instalado, ele preenche quase tudo sozinho.

**Como instalar:** copie a mensagem do [COMECE-AQUI.md](COMECE-AQUI.md) e cole no Claude. Ele faz o resto e só para quando precisa de você.

Dois vencimentos para pôr na agenda (o token do GitHub e os 60 dias sem post): veja [docs/manutencao.md](docs/manutencao.md).
